# Image Uploads

Use this folder for website images that should be available publicly in the app.

After uploading an image here, reference it in the code like this:

```tsx
<img src="/uploads/your-image-name.jpg" alt="Description" />
```

Recommended formats:
- `.webp` for best performance
- `.jpg` for photos
- `.png` for transparent logos/icons

Keep filenames simple, lowercase, and hyphenated, for example:

```text
marlene-brits-profile.webp
menlyn-maine-office.webp
team-photo.webp
```
