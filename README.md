# Marlene Brits Attorneys Website

Modern Next.js website project for Marlene Brits Attorneys.

## Tech stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Shadcn/Radix UI components
- Prisma

## Getting started

```bash
npm install
npm run dev
```

Or with Bun:

```bash
bun install
bun run dev
```

## Environment

Create a `.env` file from `.env.example` and update the database path if needed.

## Notes

Runtime/private artifacts were intentionally not committed: `.env`, local SQLite database files, agent logs, generated tool outputs, and uploaded research/source files.
